# afterlight.github.io
Site officiel du jeu vidéo AFTERLIGHT.

## Pages

- `index.html` : accueil
- `releases.html` : actualités et avancement
- `forum.html` : forum de démonstration
- `account.html` : création et gestion d'un compte de démonstration
- `download.html` : disponibilité du jeu
- `lore.html` : page prévue pour le lore détaillé

Le compte et le forum sont uniquement des prototypes côté navigateur : les données ne sont pas envoyées à un serveur et ne sont pas partagées entre visiteurs. Ne pas utiliser de mot de passe réutilisé. Une authentification et un forum réels nécessiteront un service côté serveur.
